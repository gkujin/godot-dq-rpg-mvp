# MVP受け入れ条件

## ゲーム進行

- [ ] タイトルから新規ゲームを開始できる。
- [ ] 町長と話すと依頼が開始される。
- [ ] 鍵付き扉が依頼開始前は開かず、開始後は開く。
- [ ] 町、草原、洞窟を移動できる。
- [ ] 草原と洞窟でランダム戦闘が発生する。
- [ ] 通常敵3種類と岩竜が表示・戦闘できる。
- [ ] 岩竜撃破後に町長へ報告するとクリア表示になる。

## 戦闘・成長

- [ ] 攻撃、ライデン、ホイミ、道具、防御、逃走が機能する。
- [ ] ボス戦では逃走できない。
- [ ] HPが0になるとタイトルへ戻れる。
- [ ] 勝利時に経験値とゴールドを得る。
- [ ] 必要経験値に達するとレベルが上がる。
- [ ] 3種類の道具が取得・消費できる。
- [ ] 武器と防具の変更が攻撃・守備に反映される。

## 保存・配布

- [ ] 3つのスロットへ個別に保存できる。
- [ ] タイトルから各スロットをロードできる。
- [ ] 現在地、能力、所持品、装備、クエスト状態が復元される。
- [ ] Windowsエクスポートが起動する。
- [ ] Webエクスポートが主要ブラウザーで起動する。
- [ ] `tests/run_all.gd`が終了コード0になる。
