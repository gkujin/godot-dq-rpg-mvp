# ローグライクMVP受け入れ条件

## 周回

- [ ] 新しい探索ごとに地形、敵、罠、宝が変わる。
- [ ] 同一seedでは同じ初期地形が再現される。
- [ ] 入口から階段まで必ず到達できる。
- [ ] 全5階を進み、最下層の番人撃破後に帰還できる。
- [ ] 死亡時に進行中の装備と地図が失われる。

## 判断と戦闘

- [ ] 移動、攻撃、待機、道具使用ごとに敵が1ターン行動する。
- [ ] 敵ごとに速度、毒、射撃、防御、ボス行動の違いがある。
- [ ] 空腹、毒、罠、祭壇が機能する。
- [ ] 薬の色と効果の対応が周回ごとに変わり、使用後に鑑定される。
- [ ] 武器と防具を比較して交換でき、巻物で強化できる。
- [ ] 8枠を超える品は拾えず、不要品を足元へ置ける。

## 保存と配布

- [ ] 毎ターン自動保存され、タイトルから再開できる。
- [ ] 死亡・帰還後は進行中データが消える。
- [ ] 最高到達階と最高スコアが端末内に残る。
- [ ] キーボード、マウス、タッチで操作できる。
- [ ] WindowsとWebの出力が生成できる。
- [ ] `tests/run_all.gd`と`tests/validate_project.py`が成功する。
