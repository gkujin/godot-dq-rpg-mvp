# 深淵の継承者 — Godot Roguelike MVP

Godot 4.7.1で動く、1プレイ15-25分のターン制ダンジョンRPGです。潜るたびに地形、敵、罠、宝が変わり、最下層の番人から「記憶の灯」を奪って帰還することが目的です。

Shattered Pixel Dungeonに見られる「短い周回」「探索と空腹の緊張」「未鑑定アイテム」「装備ビルド」「深追いか撤退か」という設計原則を参考にしていますが、コード、画像、文章、名称、データは流用していません。本作は独自実装で、引き続きMIT Licenseです。

## ゲームの特徴

- 部屋と通路で構成されるランダム生成ダンジョン全5階
- 1マス動くと敵も動くターン制の位置取り戦闘
- 6種類の敵AIと最下層ボス
- 視界と探索済み領域を分けたフォグ・オブ・ウォー
- ターンごとに減る空腹、毒、罠、血染めの祭壇
- 色と効果の対応が周回ごとに変わる4種類の未鑑定薬
- 武器、防具、強化の巻物、地図の巻物、保存食
- 所持上限8枠による取捨選択
- 経験値、レベルアップ、スコア、最高到達階の端末内記録
- 毎ターン自動保存と探索再開
- Windows／Web向け出力

## 操作

| 操作 | キー |
|---|---|
| 移動・敵へ攻撃 | 方向キー / WASD |
| 階段・祭壇を使う | Enter / E |
| 1ターン待機 | Space / R |
| 所持品を順に選択 | I / Tab |
| 所持品スロット選択 | 1〜8 |
| 選択した品を使用・装備 | F |
| メニュー | Esc |

マウスとタッチ操作にも対応しています。

## 起動

1. [Godot 4.7.1](https://godotengine.org/) Standard版でこのフォルダーをインポートします。
2. `project.godot`を開きます。
3. `F5`で実行します。

## 検証

```bash
godot --headless --path . --script tests/run_all.gd
python3 tests/validate_project.py
```

テストでは複数seedの到達可能性、同一seedの再現性、ターンと空腹、未鑑定薬、装備交換、階層移動、セーブ復元、フォントを検証します。
