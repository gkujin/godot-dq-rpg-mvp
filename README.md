# 竜のしるし — Godot RPG MVP

Godot 4.7.1で動く、初期ドラゴンクエスト風の2DコマンドRPGです。町で依頼を受け、草原と洞窟を進み、ボスを倒して町長へ報告するまでの30～45分の縦切り版です。

外部画像、フォント、会話アドオンには依存していません。キャラクターとマップはGodotの描画APIで表示するため、リポジトリだけで起動できます。

## 実装済み

- タイトル、新規開始、3スロットのセーブ／ロード
- 町、フィールド、洞窟の3マップと4方向移動
- NPC会話、宝箱、鍵付き扉、フラグ式クエスト
- 歩数式ランダムエンカウント
- 正面表示のラウンド制戦闘
- 攻撃、呪文、道具、防御、逃走
- 通常敵3種類とボス1体
- 呪文2種類、道具3種類、武器／防具装備
- 経験値、レベルアップ、ゴールド、全回復
- Windows／Web用エクスポートプリセット

## 起動方法

1. [Godot 4.7.1](https://godotengine.org/) Standard版でこのフォルダーをインポートします。
2. `project.godot` を開きます。
3. `F6`ではなく`F5`でプロジェクト全体を実行します。

操作は方向キーで移動、`Enter`または`Space`で決定・会話、`Esc`でセーブメニューです。戦闘コマンドはマウスまたはキーボードで選べます。

## 最短攻略

1. 町長から「岩竜の脅威」を受ける。
2. 町の東にある倉庫の扉を開け、防具を入手する。
3. 南口から草原へ出て、北東の洞窟へ向かう。
4. 洞窟の宝箱から武器と回復道具を入手する。
5. 岩竜を倒し、町長へ報告する。

## 検証

Godotがインストール済みなら、UIなしの戦闘・セーブテストを実行できます。

```bash
godot --headless --path . --script tests/run_all.gd
```

GodotがないCI環境では、参照切れ、括弧、必須MVP定義を検証します。

```bash
python3 tests/validate_project.py
```

設計の詳細は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)、MVP受け入れ条件は [docs/MVP_ACCEPTANCE.md](docs/MVP_ACCEPTANCE.md) を参照してください。
